A complete collection of Android mobile application development practical programs mapped to the **Savitribai Phule Pune University (SPPU)** computer engineering syllabus. Covers foundational and advanced Android components including Activities, Fragments, Intents, RecyclerViews, GridViews, and WebViews.

---

## 🌟 Practical Assignments Catalog

### 1. 🔄 Activities & Fragments
- `ActFragBillApp.txt` & `FragMyBillApp.txt`: Multi-fragment billing and payment processing app.
- `Act_Frag_Movie.txt`: Movie catalog demonstrating fragment-to-activity lifecycle communication.
- `Fragment_toursim.txt`: Tourism destination explorer using modular UI fragments.

### 2. 🎯 Intent Navigation
- `ExplicitHospitalApp.txt` & `Explicit_res.txt`: Explicit Intent navigation passing patient data between screens.
- `ImplicitFitnessApp.txt` & `Implicit_res.txt`: Implicit Intent invoking native dialer, maps, and system apps.

### 3. 📋 Dynamic Lists & Grids
- `RecyclerMovieApp.txt`, `RecyclerSportApp.txt`, `Recycler_BeautyApp.txt`: Custom `RecyclerView.Adapter` with `ViewHolder` caching for high-performance scrolling.
- `Grid_cllgadd.txt` & `Grid_food.txt`: 2D `GridView` item selection layouts.

### 4. 🌐 Embedded Browsing & WebViews
- `WbView-ShoppingApp.txt` & `WebView-RestaurantApp.txt`: In-app browser engine with enabled JavaScript interfaces.

## 🚀 How to Run in Android Studio

1. Open **Android Studio** and create a new project with an **Empty Activity**.
2. Copy the Java code from the respective practical file into `MainActivity.java`.
3. Copy the XML UI layout elements into `res/layout/activity_main.xml`.
4. Ensure appropriate permissions are declared in `AndroidManifest.xml` (e.g., `<uses-permission android:name="android.permission.INTERNET"/>` for WebViews).
5. Run on an Android Virtual Device (AVD) or physical device via USB debugging.
